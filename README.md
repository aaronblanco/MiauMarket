# MiauMarket v2

Aplicacion Android para explorar productos para gatos, con autenticacion por API, sesion persistida en DataStore y catalogo con busqueda.

## Tecnologias principales

- Kotlin + Jetpack Compose
- Retrofit + Moshi
- Hilt (inyeccion de dependencias)
- Jetpack DataStore (sesion)
